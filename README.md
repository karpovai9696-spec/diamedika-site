# Диамедика — статический сайт

Первая версия сайта сети центров амбулаторного гемодиализа «Диамедика» в стиле
«Диалам+»: локальные шрифты, CSS/JS без сборки и внешних CDN.

## Страницы

- `index.html` — главная
- `o-klinike.html` — о клинике
- `uslugi.html` — услуги
- `gostevoj-dializ.html` — гостевой диализ
- `kontakty.html` — четыре центра в Москве
- `licenzii.html` — лицензии и документы
- `politika-obrabotki-pdn.html` — политика обработки ПДн
- `soglasie-na-obrabotku-pdn.html` — согласие на обработку ПДн
- `sitemap.html` — карта сайта
- `404.html` — ошибка
